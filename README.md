# WebGIS Banjir - Kabupaten Bandung

Sistem informasi geospasial untuk inventarisasi genangan banjir.

## Fitur
- Peta interaktif (MapLibre GL JS)
- Filter dinamis (tahun, kecamatan)
- Input data admin
- Ekspor laporan

## Setup
1. npm install
2. Sesuaikan .env
3. Jalankan database PostGIS
4. npm run dev
