# Client Demo Scope

## Included
- Modern UI/UX dashboard.
- Interactive geospatial visualisation.
- 2023/2024 legacy data adapter.
- Filters, statistics, table, detail panel, CSV export and print.
- Lightweight static Node server with `/health`.

## Explicitly deferred
- Authentication and roles.
- Admin CRUD / data entry.
- PostgreSQL/PostGIS migration.
- REST API.
- Automated PDF report composition.
- Production backup, observability, and audit log.

The deferred items are suitable for Phase 2 after client approval.
